# Project 07 — Matrix Rain  
**PT-BR:**  
Parte da série SantsCoder, este projeto mostra como criar um efeito Matrix Rain Minimalista usando HTML, CSS e JavaScript.
A chuva digital possui visual vermelho glitch, canvas fullscreen e animação automática em looping contínuo.

**EN:**  
Part of the SantsCoder series, this project shows how to create a Minimalist Matrix Rain effect using HTML, CSS and JavaScript.
The digital rain features a red-glitch look, fullscreen canvas and an automatic looping animation.

---

## 🛠 Tecnologias / Technologies
- HTML  
- CSS  
- JavaScript  

---

## ▶ Como usar (PT-BR)
1. Baixe ou clone o repositório  
2. Abra `index.html`  
3. Ajuste velocidade, tamanho da fonte ou densidade da chuva no script

## ▶ How to use (EN)
1. Download or clone this repository  
2. Open `index.html`  
3. Adjust magnetic intensity and distance in the script
